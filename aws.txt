# 🚀 FULL AWS EC2 DEPLOYMENT FLOW (CLEAN VERSION)

---

## 🧱 1. Update server

```bash
sudo apt update && sudo apt upgrade -y
```

---

## 🌐 2. Install Nginx

```bash
sudo apt install nginx -y
sudo systemctl start nginx
sudo systemctl enable nginx
sudo systemctl status nginx
```

---

## 🐳 3. Install Docker

```bash
sudo apt install docker.io -y
sudo systemctl start docker
sudo systemctl enable docker
```

Check version:

```bash
docker --version
```

---

## 🧩 4. Install Docker Compose (if needed)

```bash
sudo apt install docker-compose -y
```

Check:

```bash
docker compose version
```

---

## 📁 5. Go to project folder

```bash
cd /var/www
```

Clone repo:

```bash
git clone <your-repo-url> AEORanker
cd AEORanker
```

---

## ⚙️ 6. Setup environment file

```bash
cp docker.env.example docker.env
nano docker.env
```

---

## 🚀 7. Build & run Docker containers

```bash
sudo docker compose up -d --build
```

Check running containers:

```bash
sudo docker ps
```

Check logs:

```bash
sudo docker compose logs -f app
```

---

## 🌐 8. Configure Nginx (VERY IMPORTANT)

Edit config:

```bash
sudo nano /etc/nginx/sites-available/default
```

Use this config:

```nginx
server {
    listen 80 default_server;
    server_name _;

    location /api/ {
        proxy_pass http://localhost:8080;

        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

---

## 🔄 9. Restart Nginx

```bash
sudo nginx -t
sudo systemctl restart nginx
```

---

## 🌍 10. Get your EC2 IP

```bash
curl ifconfig.me
```

---

## 🧪 11. Test deployment

Backend test:

```bash
curl http://YOUR_IP/api/v1/auth/me
```

Health test:

```bash
curl http://YOUR_IP/api/health
```

-
  EC2 deployment workflow

  # 1. Start infra (postgres, redis, pgadmin, redis-commander)
  docker compose up -d

  # 2. Build and start the app container
  docker compose --profile production up -d --build

  # 3. First time only — seed roles, permissions, demo data
  docker compose exec app pnpm seed

  # 4. To re-seed anytime (safe — seed is idempotent)
  docker compose exec app pnpm seed

  Migrations run automatically on every container startup via entrypoint.sh — no manual step needed there.

  ---
  Note

  You need a docker.env file on the EC2 instance (the app service reads env_file: docker.env). Copy .env.example and fill in the real values before running.


🚀 AWS EC2 Deployment Workflow
🟢 1. Connect to AWS EC2 Server

First go to folder where your .pem key exists:

cd /path/to/pem-file

Then connect:

ssh -i "hostname.pem" ubuntu@ec2-52-212-177-154.eu-west-1.compute.amazonaws.com
🟢 2. Open Project Folder

If needed:

cd /var/www/AEORanker

See all files:

ls -a
🟢 3. Check Docker Containers Running
sudo docker ps
🟢 4. Check App Logs

Use actual container name first:

sudo docker ps

Then logs:

sudo docker logs aeoranker-app-1

Live logs:

sudo docker logs -f aeoranker-app-1

⚠️ sudo docker logs app only works if container is literally named app.

🟢 5. Pull Latest Code
git pull origin main
🟢 6. Rebuild + Restart Docker App
sudo docker compose --profile production up -d --build

This:

✔ rebuilds image
✔ updates code
✔ restarts services
✔ keeps DB volumes safe

🟢 7. Verify After Deploy
sudo docker ps
sudo docker logs aeoranker-app-1
🟢 8. Nginx Config File

Edit:

sudo nano /etc/nginx/sites-available/default
🟢 9. Test Nginx Config
sudo nginx -t
🟢 10. Reload Nginx
sudo systemctl reload nginx

Restart fully if needed:

sudo systemctl restart nginx
🟢 11. Check Public IP

Correct command:

curl ifconfig.me

(You wrote iconfig.me, typo)

Alternative:

curl ipinfo.io/ip
🟢 12. Test Domain / DNS
curl https://yourdomain.com

or:

nslookup yourdomain.com
